# MServen Gen 2.0 - Minecraft Server Manager

![PRIMUS CORP](https://img.shields.io/badge/PRIMUS%25CORP-v2.0-red)
![Python](https://img.shields.io/badge/Python-3.x-blue)
![CustomTkinter](https://img.shields.io/badge/GUI-CustomTkinter-orange)

MServen Gen 2.0 est un outil d'automatisation et de gestion complet conçu pour simplifier la création, le lancement et la configuration de serveurs Minecraft directement depuis une interface graphique moderne et intuitive.

---

## 🚀 Fonctionnalités principales

* **Assistant de création rapide :** Choix de la version de Minecraft, allocation de RAM personnalisable via un curseur intelligent et acceptation automatique/interactive de l'EULA.
* **Téléchargement automatisé :** Récupération directe et vérification d'intégrité du fichier `server.jar` depuis les serveurs officiels Mojang.
* **Éditeur de configuration intelligent :** 
  * Gestion complète du fichier `server.properties` avec les paramètres principaux traduits en français.
  * **Onglet "Avancé"** dédié aux options expertes du `server.properties` pour les utilisateurs avancés.
* **Éditeur de MOTD intégré :** Aperçu en direct du texte d'accueil avec support des codes de couleurs et de styles officiels de Minecraft (`§`).
* **Console de lancement dédiée :** Démarrage simplifié du serveur avec une gestion propre de l'initialisation.
