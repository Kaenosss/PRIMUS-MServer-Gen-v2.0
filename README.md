# 🎮 MServer Gen 2.1 - Minecraft Server Manager

---

> MServer Gen 2.0 est un outil d'automatisation et de gestion complet
> conçu pour simplifier la création, le lancement et la configuration de
> serveurs Minecraft directement depuis une interface graphique.

<br>

### ☕ Java

La création du serveur nécessite l'installation d'une instance Java
propre à la version du serveur choisie. L'utilitaire est disponible à
cette adresse : https://adoptium.net/fr

---

## ⚙️ Fonctionnalités principales

### 🧙 Assistant de création rapide

* Assistant de création rapide : Choix de la version de Minecraft,
  allocation de RAM personnalisable et acceptation automatique de l'EULA.

### 📥 Téléchargement automatisé

* Téléchargement automatisé : Récupération directe et vérification d'intégrité du fichier server.jar depuis l'API de Mojang.

### 📝 Gestion de `server.properties`

* Gestion complète du fichier server.properties avec les paramètres principaux traduits en français/anglais.

### 🔧 Onglet "Avancé"

* Onglet "Avancé" dédié aux options poussées du server.properties.

### 🖥️ Console de lancement dédiée

* Console de lancement dédiée : Démarrage simplifié du serveur avec la génération d'un fichier .bat optimisé.

### ☕ Onglet "Java"

* Onglet "Java" permettant d'installer les runtimes Java adéquates pour
  le serveur, possibilité de modifier le PATH sur la version de Java
  voulue directement dans le logiciel.
